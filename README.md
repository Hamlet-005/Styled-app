# Seven Design Styles

A responsive React and TypeScript showcase with exactly seven routed pages. Each page has its own visual system and is implemented with styled-components.

## Routes

- `/minimalist`
- `/cyberpunk`
- `/glassmorphism`
- `/neumorphism`
- `/brutalist`
- `/retro`
- `/luxury`

## Installation

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

React, TypeScript, Vite, React Router, and styled-components.
